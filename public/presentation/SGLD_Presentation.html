Student Governance & Leadership Development

Building Leaders • Empowering Choices • Shaping the Future

Problem & Opportunity

Problem

  • Students lack a single platform for raising concerns, voting, and accessing governance documents.

Opportunity

  • Deliver a secure, easy-to-use platform that centralises student governance.

Key Features

  • Role-based dashboards for Students, SRC, SFC and Admin
  • Concerns/cases submission and tracking
  • News & events publishing
  • Document management with in-app PDF preview

Demo Flow

  1. Landing page & role-aware login
  2. Submit and track a concern
  3. Admin/SRC/SFC review and respond
  4. Publish news and share documents

Architecture (high level)

Frontend: React + Vite
Backend: Supabase (Postgres + Storage + Auth)
Hosting/Deployment: CI/CD on push (Vercel/Netlify)

Recent Changes

  • In-app document preview modal with PDF embed and loading spinner
  • Modal styling and layering fixes so preview overlays other UI
  • Removed some roles from login selection per product decision

Next Steps

  • Add analytics and error monitoring
  • Improve PDF accessibility and printing
  • User onboarding and tutorials
